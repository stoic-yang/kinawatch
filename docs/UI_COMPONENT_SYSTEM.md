# Journal 组件与配色

适用范围：v0.2.0 默认首页的日记、时间线、节律、健康、信念页面及其侧栏、编辑器和浮层。正式入口为 `frontend/src/main.tsx`；其他布局实验仅保留作开发参考。

## 维护入口

- `frontend/src/experiments/concepts/palettes.ts`：石墨、素白、钴蓝、陶土、曜石五套语义配色。默认石墨采用白色工作区、浅灰导航和蓝色交互强调；曜石使用 dark color scheme。五套配色共用同一布局与交互状态。
- `component-system.css`：统一卡片、按钮、分段切换、统计标签、表单、反馈、焦点、文字层级与页面间距。
- `PalettePicker.tsx` / `palette-picker.css`：侧栏外观入口；原生 popover 和单选控件支持键盘、Escape 及点击外部关闭，弹层根据入口位置选择上方或下方并限制在窗口内。
- `shared.tsx` / `sidebar-collapse.css`：各页共用的侧栏收起状态、图标导航和窄屏布局。
- `HealthPage.tsx` / `personalHealth.ts` / `health.css`：健康页和日记的当日摘要，共用一份导入快照及选中日期；统计口径见 `PERSONAL_HEALTH.md`。
- `components/DatePicker.tsx` / `date-picker.css`：健康页使用统一字体与语义配色的日历弹层，复用 `lib/calendar.ts` 的周一开头月历；支持选中日期、未来禁用、翻月、今天、方向键、Home/End、PageUp/PageDown（Shift 按年）、Escape 和外部点击关闭。
- `BeliefsPage.tsx` / `beliefs.css`：与日期无关的信念文稿、直接编辑、目录、自动保存和文件版本对照。
- `rhythm-workspace.css` / `annual-rhythm.css`：各自负责图表布局，颜色使用共享语义变量。小时热力图与年度热力图共用同一明暗方向。
- `JournalTimeline.tsx` / `journal-timeline.css`：日记参考栏的竖向时间轴；`journalTimelineModel.ts` 负责真实时间比例、缩放边界、动态刻度与短活动命中。
- `SessionList.tsx` / `session-description-dialog.css`：工作流描述的紧凑预览、完整阅读与显式保存浮层；`descriptionLayout="below"` 的其他布局继续使用原有行内编辑。

颜色只在 palette 层定义。新增组件使用 `--kw-ui-*` 与 `--kw-heat-*`，避免在特性样式中新增固定颜色。活动类别继续使用原有类别颜色，保持不同页面的分类含义一致。错误、警告与保存成功有各自的状态色。

## 共用规则

- 界面正文 13–15px，日记正文 16px、行高 2；辅助信息 11–12px，图表刻度与图例可以使用 9–10px。使用系统字体与苹方，不加载外部字体。
- 面板标题 15–16px，独立页面标题 28px，日记日期 34px；窄屏主标题 24px，数字使用 tabular numerals。
- 卡片圆角 10px，控件圆角 7px，分段控件外框 8px；统计标签为胶囊形。日记桌面工作区不使用卡片外框。
- 普通控件基准高度 32px，统计标签保持 27px，卡片内使用 14–18px 的紧凑留白。
- 时间线与节律共用 1284px 内容宽度、32px 桌面页边距、16px 窄屏页边距。日记保留文稿与参考栏的写作布局。
- 选中、悬停、焦点、禁用、错误状态都使用对应语义颜色。Portal 浮层从文档根节点继承配色。
- 主导航依次为「日记」「时间线」「节律」「健康」「信念」。展开宽度与日记两侧参考栏共用 `--kw-ui-sidebar-width: 224px`，只保留品牌、主导航和外观，顶部按钮可收起为 68px 图标栏，保留可访问名称、悬停标题与当前页标记。`kinawatch.sidebar.collapsed.v1` 只保存本机导航布局偏好，不影响日记右栏。外观入口位于左栏底部；820px 及以下改为顶部紧凑导航，外观入口与导航同行。480px 及以下导航使用图标上、文字下的紧凑布局，让五个入口同时可见。折叠不重新挂载正文编辑器。
- 时间线工作流在桌面端使用活动、描述等宽的两列；描述只显示两行预览，通过「展开」查看全文。添加与编辑使用独立的原生模态浮层，长内容在浮层内部滚动，列表不随描述长度或编辑状态增高。容器不足 760px 时两列上下排列。浮层宽度最多 640px，编辑高度最多 500px，并限制在可见窗口内；取消、保存按钮至少为 56 × 30px。打开编辑器聚焦输入框，关闭后返回原入口；保存期间禁止关闭和重复提交，失败与冲突保留草稿。
- 节律与年度活动的标题栏直接连接图表，不再单设「每日活动」标题或色阶提示行。
- 健康页的 7/30 天切换、周期导航、日期选择与导入合并在标题行；采用居中的开放内容区，最大宽度 1168px（含两侧 48px 留白），顶部留白 48px。睡眠与步数总览、睡眠趋势、作息和步数趋势共五个区域去掉卡片外框，以少量分隔线和 28–48px 的间距分组；睡眠时长优先突出，图表使用适度的固定高度与较细柱形。低于 760px 高的桌面窗口适当收紧间距，1280×720 仍可一屏查看全部内容。窄屏自然换行与滚动，保留完整数据和操作。底部数据说明继续保持移除。
- 日记使用连续的全高工作区：224px 时间线、弹性宽度文稿与 224px 当日信息栏，用细分隔线区分。右栏使用浅底，正文与日期标题共用不超过 760px 的阅读宽度，日期与星期分行。正文上方留白 58px，桌面参考栏固定在视口内、内容独立滚动。日记保持安静的自动保存，不显示常驻保存状态；读取失败、保存失败或版本冲突仍在正文下方提供反馈与处理入口。
- 日记右栏依次为日历、健康、主要分类、主要应用；复用同一日期与分类筛选状态，日历与分类、应用三项可独立折叠。健康仅显示睡眠时长与步数，标签和数字同行，不提供跳转入口或估算附注。切换其他页面时隐藏但不卸载，返回后保留选择；左侧导航收起不影响它们。桌面分栏保持统一宽度，不再单独收紧时间线栏；日记容器不超过 900px 时时间线移至正文下方，右栏仍位于正文右侧；不超过 660px 时当日信息位于正文上方，时间线位于正文下方。820px 及以下窗口默认折叠三项，用户已经作出的展开或收起选择继续保留。
- 日记左侧使用连续竖向时间线，默认显示全天和原有分类颜色；每段长度对应真实起止时间，空闲区间留白。顶部显示「时间线」，下方突出屏幕时长；桌面轨道最大宽度 72px，随栏宽收紧，高度随窗口调整。有大纲时适当收短图表以留出标题列表；移至正文下方时图表填满可用宽度、高度为 360px。图上不常驻显示应用名称，详情放入悬停或键盘选择的浮层。浮层显示起止时间、时长与应用名，并以主要文字显示所选活动的原始标签页／窗口标题；长标题自动换行，空标题只保留应用信息，工作流描述继续作为补充。滚轮以指针所在时间为中心缩放，最小视窗为五分钟，刻度随范围变细；放大后拖动或 Shift 加滚轮平移，双击、0 或图表右上角的复位按钮恢复全天。上下方向键逐条浏览并自动显示视窗外的活动，Home / End 定位首尾，加减键缩放，PageUp / PageDown 平移，Escape 关闭详情。切换日期恢复全天，分类筛选保留视窗；页面或数据变化清除旧选择。时间线页的工作流分组与描述编辑保持独立。

`journalPresentation.ts` 维护正文与完整文件之间的位置映射，分栏展示不重排或删除总结原文。已识别的工作流描述也从正文与大纲中隐藏，只在时间线的工作流入口查看和编辑；普通用户自写的「工作流」Callout 不会仅凭标题被隐藏。编辑时将结构性空行归入隐藏区域，避免全选重写或保存确认移动光标；全选清空正文仍逐字保留原有工作流与总结。外部文件更新仍通过原有版本冲突流程处理。`MarkdownDocumentEditor.tsx` 提供标题、强调、代码、Callout 与任务列表的实时显示，当前编辑行保留 Markdown 语法，KinaWatch 内部注释不作为正文显示。

工作流保存成功后，`App.tsx` 立即将接口确认的文字和文件版本应用到当前日期，再重新读取当日活动。只有当前缓存仍对应编辑开始时的版本，才应用该保存结果；已打开的其他描述继续保留各自的编辑版本和草稿。整页刷新延迟或失败不会让再次编辑带回旧文字。

已有描述可以清空后显式保存，只有新建且未填写的描述禁用保存。清空保留所选时间的空记录，列表恢复「添加描述」；重新读取后不会恢复旧文字或 Kina 回退描述。生成总结原文保持只读，其他描述不受影响，空草稿同样参与版本冲突检查。

## 切换与验证

`?palette=graphite|porcelain|cobalt|clay|charcoal` 可直接预览指定配色；用户切换时保存至 `kinawatch.appearance.palette`，刷新与页面导航后保留选择。旧参数与已保存的 `sea` / `sand` / `iris` / `night` 分别映射到钴蓝 / 陶土 / 素白 / 曜石。切换只改变显示属性，不重新挂载编辑器。

信念入口为 `#beliefs`，读取配置中固定的 `journal.beliefs_note_path`，默认 `Review/我的人生信念.md`。在写入启用时，正文直接使用日记同款 Markdown 编辑器，无需进入编辑模式，也不提供 Obsidian 跳转入口。标题生成右侧目录；窄屏目录移至正文上方且默认折叠。与页面同名的开头 H1 不重复显示，其原始前缀在保存时保留。输入暂停约 700ms 后自动保存，不显示常驻保存按钮或状态；读取不写文件，保存期间仍可继续编辑。未同步草稿保存在本机 `kinawatch.beliefs.draft.v1`，兼容旧编辑器留下的草稿，页面切换或刷新可恢复并继续同步；后台读取与较早的保存响应不得覆盖新输入。信念与日记复用 `documentAutosave.ts` 的串行保存、失败恢复与冲突处理；网络失败时先重读确认文件版本再重试。文件版本变化时保留草稿，核对后再明确选择版本。YAML 属性保持原样，日记、常驻笔记和来源笔记不参与更新。

正式构建：`npm run build --prefix frontend`，产物在 `dist/`，由 Python 后端直接托管。主入口固定使用 Journal，不依赖端口或预览参数。

开发概念构建：`npm run build --prefix frontend -- --config vite.concepts.config.ts`，产物在被忽略的 `output/playwright/ui-concepts/dist`。

回归检查：`npm run test:journal --prefix frontend` 与 `python3 -m unittest discover -s tests -p 'test_*.py' -v`。写入检查必须使用合成数据。浏览器重点验证编辑与保存、草稿恢复、版本冲突、描述清空、原文保留、时间轴缩放、标题详情、侧栏收起、五套配色以及桌面和窄屏边界。真实笔记与 ActivityWatch 仅做只读检查。

## 视觉精修

五个页面共用语义配色、7px 控件圆角和 32px 标准控件高度；使用卡片的区域统一为 10px 圆角，日记与健康采用开放布局。分隔线使用 `--kw-ui-separator`，日记取消外层卡片、阴影与卡片间距，使用连续的正文和两侧参考区域。统计标签使用无描边的浅底，分段选择器以纸面底色和轻阴影表达选中；工作流描述入口为轻量文字按钮，悬停与键盘焦点始终可见。

侧栏底色直接使用各配色的 rail，选中导航使用表面色和轻阴影，图标使用强调色，不再附加状态圆点。健康、信念与其他独立页面共用标题与控件层级。热力图正常数据格弱化描边，但缺失、异常和不完整状态保留各自标记。控件使用 140ms 的颜色反馈，浮层轻微淡入；减少动态效果偏好下禁用新增动画。描述编辑器只显示一层清晰焦点边框。
