# Journal 组件与配色

适用范围：v0.2.0 默认首页的日记、时间线、节律、信念页面及其侧栏、编辑器和浮层。正式入口为 `frontend/src/main.tsx`；其他布局实验仅保留作开发参考。

## 维护入口

- `frontend/src/experiments/concepts/palettes.ts`：石墨、素白、钴蓝、陶土、曜石五套语义配色。默认石墨，色值保持原样；曜石使用 dark color scheme。其他四套已按新反馈更换。
- `component-system.css`：统一卡片、按钮、分段切换、统计标签、表单、反馈、焦点、文字层级与页面间距。
- `PalettePicker.tsx` / `palette-picker.css`：侧栏外观入口；原生 popover 和单选控件支持键盘、Escape 及点击外部关闭，弹层根据入口位置选择上方或下方并限制在窗口内。
- `shared.tsx` / `sidebar-collapse.css`：四页共用的侧栏收起状态、图标导航和窄屏布局。
- `BeliefsPage.tsx` / `beliefs.css`：与日期无关的信念文稿、目录、显式编辑保存和文件版本对照。
- `rhythm-workspace.css` / `annual-rhythm.css`：各自负责图表布局，颜色使用共享语义变量。小时热力图与年度热力图共用同一明暗方向。
- `JournalTimeline.tsx` / `journal-timeline.css`：日记参考栏的竖向时间轴；`journalTimelineModel.ts` 负责真实时间比例、缩放边界、动态刻度与短活动命中。
- `SessionList.tsx` / `session-description-dialog.css`：工作流描述的紧凑预览、完整阅读与显式保存浮层；`descriptionLayout="below"` 的其他布局继续使用原有行内编辑。

颜色只在 palette 层定义。新增组件使用 `--kw-ui-*` 与 `--kw-heat-*`，避免在特性样式中新增固定颜色。活动类别继续使用原有类别颜色，保持不同页面的分类含义一致。错误、警告与保存成功有各自的状态色。

## 共用规则

- 正文 13–15px，辅助信息 11–12px；图表刻度与图例可以使用 9–10px。
- 面板标题 16px，日期主标题 24–26px；数字使用 tabular numerals。
- 卡片圆角 10px，控件圆角 6px，分段控件外框 8px；统计标签为胶囊形。
- 普通控件基准高度 30px，统计标签保持 27px，卡片内使用 14–18px 的紧凑留白。
- 时间线与节律共用 1284px 内容宽度、32px 桌面页边距、16px 窄屏页边距。日记保留文稿与参考栏的写作布局。
- 选中、悬停、焦点、禁用、错误状态都使用对应语义颜色。Portal 浮层从文档根节点继承配色。
- 主导航依次为「日记」「时间线」「节律」「信念」。侧栏顶部按钮可收起为 68px 图标栏，保留可访问名称、悬停标题与当前页标记；日历、分类与应用隐藏但不卸载，展开恢复各自状态。`kinawatch.sidebar.collapsed.v1` 只保存本机布局偏好，页面导航与刷新保留选择。外观入口位于侧栏底部；820px 及以下改为顶部紧凑导航，收起时隐藏分区，外观入口与导航同行。折叠不重新挂载正文编辑器。
- 时间线工作流在桌面端使用活动、描述等宽的两列；描述只显示两行预览，通过「展开」查看全文。添加与编辑使用独立的原生模态浮层，长内容在浮层内部滚动，列表不随描述长度或编辑状态增高。容器不足 760px 时两列上下排列。浮层宽度最多 640px，编辑高度最多 500px，并限制在可见窗口内；取消、保存按钮至少为 56 × 30px。打开编辑器聚焦输入框，关闭后返回原入口；保存期间禁止关闭和重复提交，失败与冲突保留草稿。
- 节律与年度活动的标题栏直接连接图表，不再单设「每日活动」标题或色阶提示行。
- 日记使用工作流、文稿和 Kina 总结三个独立面板，面板间距 16px、页面边距 24px；参考栏使用浅底色，文稿使用纸面色。正文与日期标题共用不超过 720px 的阅读宽度，日期与星期分行。日记保持安静的自动保存，不显示常驻保存状态；读取失败、保存失败或版本冲突仍在正文下方提供反馈与处理入口。
- 已识别的 Kina 总结与建议显示在右侧参考栏，正文大纲只包含可编辑文稿的标题；无标题时隐藏整个大纲区域。工作流宽度为 216–244px，总结宽度为 280–332px。日记容器小于 1040px 时总结移至正文下方，小于 660px 时按正文、工作流、总结排列；无总结时保留两栏布局。
- 日记左侧使用连续竖向时间线，默认显示全天和原有分类颜色；每段长度对应真实起止时间，空闲区间留白。顶部左侧显示「工作流」，右侧以普通文字显示屏幕时长；图表填满扣除刻度后的可用栏宽，有大纲时适当收短图表以留出标题列表。图上不常驻显示应用名称，详情放入悬停或键盘选择的浮层。浮层显示起止时间、时长与应用名，并以主要文字显示所选活动的原始标签页／窗口标题；长标题自动换行，空标题只保留应用信息，工作流描述继续作为补充。滚轮以指针所在时间为中心缩放，最小视窗为五分钟，刻度随范围变细；放大后拖动或 Shift 加滚轮平移，双击、0 或图表右上角的复位按钮恢复全天。上下方向键逐条浏览并自动显示视窗外的活动，Home / End 定位首尾，加减键缩放，PageUp / PageDown 平移，Escape 关闭详情。切换日期恢复全天，分类筛选保留视窗；页面或数据变化清除旧选择。时间线页的工作流分组与描述编辑保持独立。

`journalPresentation.ts` 维护正文与完整文件之间的位置映射，分栏展示不重排或删除总结原文。已识别的工作流描述也从正文与大纲中隐藏，只在时间线的工作流入口查看和编辑；普通用户自写的「工作流」Callout 不会仅凭标题被隐藏。编辑时将结构性空行归入隐藏区域，避免全选重写或保存确认移动光标；全选清空正文仍逐字保留原有工作流与总结。外部文件更新仍通过原有版本冲突流程处理。`MarkdownDocumentEditor.tsx` 提供标题、强调、代码、Callout 与任务列表的实时显示，当前编辑行保留 Markdown 语法，KinaWatch 内部注释不作为正文显示。

工作流保存成功后，`App.tsx` 立即将接口确认的文字和文件版本应用到当前日期，再重新读取当日活动。只有当前缓存仍对应编辑开始时的版本，才应用该保存结果；已打开的其他描述继续保留各自的编辑版本和草稿。整页刷新延迟或失败不会让再次编辑带回旧文字。

已有描述可以清空后显式保存，只有新建且未填写的描述禁用保存。清空保留所选时间的空记录，列表恢复「添加描述」；重新读取后不会恢复旧文字或 Kina 回退描述。生成总结原文保持只读，其他描述不受影响，空草稿同样参与版本冲突检查。

## 切换与验证

`?palette=graphite|porcelain|cobalt|clay|charcoal` 可直接预览指定配色；用户切换时保存至 `kinawatch.appearance.palette`，刷新与页面导航后保留选择。旧参数与已保存的 `sea` / `sand` / `iris` / `night` 分别映射到钴蓝 / 陶土 / 素白 / 曜石。切换只改变显示属性，不重新挂载编辑器。

信念入口为 `#beliefs`，读取配置中固定的 `journal.beliefs_note_path`，默认 `Review/我的人生信念.md`。页面以阅读为默认状态，标题生成右侧目录；窄屏目录移至正文上方且默认折叠。阅读时省略与页面同名的开头 H1，编辑及保存仍使用完整原文。点击「编辑信念」后编辑完整 Markdown 正文，点击「保存」才更新文件；读取与输入都不写入文件。取消放弃当前草稿，清空已有内容也能显式保存。草稿仅保存在本机 `kinawatch.beliefs.draft.v1`，页面切换或刷新可恢复；文件版本变化时保留草稿，核对后再明确选择版本。YAML 属性保持原样，日记、常驻笔记和来源笔记不参与更新。

正式构建：`npm run build --prefix frontend`，产物在 `dist/`，由 Python 后端直接托管。主入口固定使用 Journal，不依赖端口或预览参数。

开发概念构建：`npm run build --prefix frontend -- --config vite.concepts.config.ts`，产物在被忽略的 `output/playwright/ui-concepts/dist`。

回归检查：`npm run test:journal --prefix frontend` 与 `python3 -m unittest discover -s tests -p 'test_*.py' -v`。写入检查必须使用合成数据。浏览器重点验证编辑与保存、草稿恢复、版本冲突、描述清空、原文保留、时间轴缩放、标题详情、侧栏收起、五套配色以及桌面和窄屏边界。真实笔记与 ActivityWatch 仅做只读检查。

## 视觉精修

四个页面共用 12px 卡片圆角、7px 控件圆角和 32px 标准控件高度。分隔线通过 `--kw-ui-separator` 弱化，正文纸面使用轻阴影，日记参考栏使用浅底色和透明边框。统计标签使用无描边的浅底，分段选择器以纸面底色和轻阴影表达选中；工作流描述入口为轻量文字按钮，悬停与键盘焦点始终可见。

侧栏底色与画布混合，保持各配色的色相与文字对比度。日记正文与两侧参考栏间距 20px，信念页与其他独立页面对齐。热力图正常数据格弱化描边，但缺失、异常和不完整状态保留各自标记。控件使用 140ms 的颜色反馈，浮层轻微淡入；减少动态效果偏好下禁用新增动画。描述编辑器只显示一层清晰焦点边框。
